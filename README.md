# SAAD Tattoo — Website Redesign (v2)

Static redesign prototype for **SAAD Tattoo Wiesbaden** (saadtattoo.de), built to be
re-implemented on **Wix Studio**. Live demo: see Vercel deployment link.

- 11 pages · DE / EN / FA (full RTL, Vazirmatn) · black monochrome + matte gold
- Design system: `../docs/DESIGN-TOKENS.md` · QA protocol: `../docs/ROLLBACK-PROTOCOL.md`
- Internal booking flow: category → service detail → date → time → confirm (Wix Bookings embed at go-live)
- No frameworks — vanilla HTML/CSS/JS, 8pt spacing scale, Major-Third type scale
